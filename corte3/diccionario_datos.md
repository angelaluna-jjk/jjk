# ¿Qué ROL es el encargado de capturar estos datos? 
 El gestor de tienda es el encargado de el encargado de registrar, catalogar y actualizar los productos en el inventario (ingresando sus nombres, dimensiones y precios de venta), permitiendo que los productos queden listos y disponibles en la plataforma para que los clientes finales puedan realizar sus compras de manera correcta.

# ¿Qué FUNCIÓN de validación debe realizar el sistema automáticamente? 
 El sistema debe validar:
 - Los usuarios ingresen según su rol (Administrador o Trabajador) y solo accedan a las funciones permitidas.
 - No se deben registrar productos con datos obligatorios vacíos o incompletos.
 - Las ventas queden registradas correctamente con fecha, cantidad y producto vendido.
 - El precio de los productos debe ser mayor a cero.
 - La cantidad de productos ingresada debe ser numérica y mayor a cero

 # ¿Qué sucede con la información del sistema si este Rol no cumple su Función?
  el sistema presentará inconsistencias graves en la información del catálogo. Esto provocará que los clientes visualicen productos con informacion erronea, afectando la experiencia de compra en la tienda online. Además, al no registrarse ni actualizarse los datos a tiempo, el inventario digital no coincidirá con el almacén físico, lo que generará retrasos en la logística y confusion en los clientes y operadores.
